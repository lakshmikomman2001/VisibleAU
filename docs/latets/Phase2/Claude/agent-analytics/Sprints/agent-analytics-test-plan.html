⚠️ The one routing fact that governs everything

There is no standalone Agent Analytics route. Every screen lives inside the existing Retrieval tab on the brand detail page. The path is always:

One honest caveat on this plan

The screen names (AA-1…AA-4) and their in-tab placement come from the prototype and LLD — the design intent. The exact visual layout (is the vendor table a separate sub-tab, or scrolled below the card?) is the prototype's call, and Claude Code may render the section slightly differently. What's binding is: it's all inside the Retrieval tab · the 4 CDN verdicts · count-card-not-score-card · caveat-on-card · the tier gates. Those are the assertions that matter; the precise screen subdivision is cosmetic.
