### D-UI1 as built

- `app/globals.css:211-222`: on text inputs, textareas and selects (not checkboxes, radios, buttons, hidden, file, range, colour or image inputs), the three border names an inline style can use (`--border-default`, `--border-strong`, `--border-subtle`) resolve to `--border-control`. Form controls style their border inline per screen (87 inputs, textareas and selects in 33 files, no shared Input), so this is the one-variable change D-UI1 describes: no screen's markup changes, decorative borders elsewhere keep their values, and focus and error borders (which use `--accent-blue`, `--border-focus` or `--danger`) are unchanged. Inputs with Tailwind's bare `border` class (`app/(auth)/brands/new/page.tsx:55` and three more) already draw a `currentColor` boundary, well above 3:1, and are unchanged.
- Switches: the app has two, both hand-built `role="switch"` buttons; their off tracks were fills under 3:1 (`--bg-active`; a 30% mix of `--text-tertiary`). Both now use `--border-control`: `app/(auth)/settings/notifications/page.tsx:47`, `components/domain/communication/schedule-form.tsx:332`.
- Checkboxes and radios (8 native ones) keep the browser's own boundary (Chromium draws #767676, 4.54:1 on white); no change.

**Font loading:** the web app loads no font. There is no `next/font`, no `<link>` and no `@font-face`: `app/layout.tsx:36-52` has none, and a repo-wide grep for `next/font|@font-face|fonts.googleapis|.woff` finds no web use. G:42 only names `'Inter', -apple-system, BlinkMacSystemFont, sans-serif` as `--font-display`. G:193-197 applies it to html/body, overriding the `body { font-family: Arial }` at G:30-34, and Tailwind's `font-sans` maps to it (G:26). The result is that Inter renders only where the visitor has it installed. Otherwise macOS gets the system UI font and Windows gets generic sans-serif, which is Arial in Chrome. Mono is `ui-monospace, 'JetBrains Mono', monospace` (G:27, G:43): SF Mono in Safari, otherwise JetBrains Mono if installed, otherwise the default monospace (Consolas on Windows). Only the PDF embeds Inter, Fraunces and JetBrains Mono, as TTFs (`lib/reports/pdf/fonts.ts:22-40`, `lib/reports/pdf/fonts/`). The CSP is `font-src 'self'` (`vercel.json`), which blocks a Google Fonts `<link>`; `next/font/google` self-hosts and would pass. `README.md:21` claims `next/font` Geist, which is stale (G:24-25 says no Geist is loaded).
